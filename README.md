# Трекер витрат Олі і Марка

Особистий трекер для двох людей, Олі і Марка. Вони разом винаймають квартиру на Мокотові, оренду й продукти ділять навпіл, решту кожен оплачує сам. Трекер не для продажу і не для інших користувачів.

Оля і Марко мають рахунки в різних банках, тож у кожного свій облік і своя виписка. Оля вивантажує виписку раз на місяць і запускає імпорт. Марко не працює з терміналом: він відкриває звіт з телефона і додає туди витрати, яких немає у виписці.

Усі дані в репозиторії штучні, з навчального завдання.

## Що показує трекер

Для кожного з двох окремо:

- витрати за категоріями по місяцях;
- дохід, відкладене і норму заощаджень;
- фіксовані витрати (тег `#fixed`) і змінні.

Фіксовані в Олі: оренда, ZTM, Netflix, Spotify, Claude.ai, Play. Фіксовані в Марка: Orange, PGE, Zdrofit, YouTube Premium. Усі інші витрати змінні.

## Перевірка однією командою

```bash
uv run python check.py
```

Команда імпортує обидві виписки з `data/`, запускає `bean-check` для обліку Олі і обліку Марка і друкує їхні змінні витрати за серпень і вересень 2026 поруч із контрольними цифрами з умови. Код виходу 0, якщо все збігається.

## Інші команди

| Що | Команда |
|---|---|
| Імпорт виписок | `uv run python import.py` |
| Перевірка обліку Олі | `uv run bean-check ledger/olia.beancount` |
| Перевірка обліку Марка | `uv run bean-check ledger/marko.beancount` |
| Збережений запит | `uv run bean-query ledger/marko.beancount ".run заощадження"` |
| Fava локально | `uv run fava ledger/olia.beancount ledger/marko.beancount -p 5050` |

## Як влаштовано

| Шлях | Що там |
|---|---|
| `data/` | виписки Олі і Марка в CSV, лише читання |
| `rules.csv` | правила категорій для обох: шаблон, рахунок, чи фіксована витрата |
| `tracker/banks.py` | читання виписок банку Олі і банку Марка |
| `tracker/ledger.py` | категорії і запис обліку |
| `ledger/olia.beancount`, `ledger/marko.beancount` | рахунки і збережені запити кожного |
| `ledger/transactions-*.beancount` | операції з виписок, генерує `import.py` |
| `ledger/manual-*.beancount` | витрати, додані з телефона |
| `deploy/wsgi_app.py` | Fava за паролем для PythonAnywhere |

## Вебверсія для Марка

Трекер працює на PythonAnywhere через HTTPS. Марко відкриває посилання з телефона, входить за паролем і бачить звіт. Кнопка + у Fava додає витрату, і вона зберігається у `ledger/manual-marko.beancount`.

Тестовий логін і пароль передаються разом зі здачею завдання, у репозиторії їх немає. Без входу сервер відповідає 401 і не показує жодних даних. Логін і пароль сервер бере зі змінних середовища `TRACKER_USER` і `TRACKER_PASSWORD` з файлу `~/.tracker.env` на сервері.
